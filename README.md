# ZSOUND

ZSOUND is a mobile-first online store for purchasing musical instruments and accessories.

## Features
- Mobile-first storefront design
- Product categories: guitars, keyboards, drums, and audio gear
- Shopping cart experience
- Responsive layout for phone and desktop browsing

## Run locally
Open `index.html` directly in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Brand
The app branding uses the name `ZSOUND` with a modern music-store identity.
